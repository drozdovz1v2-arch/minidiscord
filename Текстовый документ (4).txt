1️⃣ Установить зависимости

Открой PowerShell или CMD в папке проекта (mini-discord) и выполни:

npm install

2️⃣ Запустить сервер для текста и авторизации

В той же папке проекта:

node server.js

3️⃣ Запустить сервер для голосового канала

В отдельном терминале:

node serverVoice.js

4️⃣ Запустить Electron-приложение

В другом терминале той же папки:

npm start


npm run build
